
### Personal Summary

Public vs Private services have nothing to do with services that one group possesses and another doesn't; it's about what network these services lie in.

There is the "Public Internet Zone", "AWS Public Zone" and the "AWS Private Zone". An EC2 lies in the private zone, while an S3 would be in the AWS public zone. 

The internet zone can access the aws public at any time, and private services can be given an IP address so they are to be accessed online from anywhere. 

A VPC is the private zone, and On-Premises can access VPC's only if configured via VPN or Direct Connect.
