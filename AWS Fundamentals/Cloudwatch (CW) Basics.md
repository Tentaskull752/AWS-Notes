
### Personal Summary

  - An app that monitors, collects, and manages operational data and metrics of environments and resources.
  - Cloudwatch agent can be used to monitor on-premises resources. Monitoring things inside products that aren't exposed to AWS require Cloudwatch agent as well.
  - Cloudwatch Logs allows the monitoring, collection, and managing of logging data. Ex. windows event logs, firewall logs, linux logs.
  - Cloudwatch Events: if a AWS service does something, ex. EC2 being terminated, it will give course of actions following this.
 
 -  Namesake: a name that sections incoming data from resources into their appropriate sections. EC2 data will go into AWS/EC2 for ex. 
 - Metric: "What is being measured?" CPU utilization %, Speed of write or copy? RAM usage?
 - Datapoint: "98.3% CPU utilization"; the answer given back when asked about a metric.
 - Dimension: InstanceID, IP, or any other identifying factors that can help identify a singular resource when others of the type type (ex. all EC2's) are sending in a datapoint every second.
