
### Personal Summary

 - IAAS - Provides structure as a service by providing virtual machines (Instances). Private services by default, using VPC networking.

 - AZ Resilient - Instance fails if AZ fails

 - Different sizes and capabilities and has on-demand billing - per second
- Can use on-host storage or EBS

 - An AMI is an Amazon Machine Image that is a copy of an EC2, and it can be used to create EC2s.  An AMI contains attached permissions, these determine which accounts can utilize the image. It can be set to public so everyone can use it. 
 - The owner explicitly is allowed to use the AMI and create EC2s.
 - The owner explicitly can allow others used to use the image and create EC2s with the image. 

 - Block Device Mapping allows the operating system to determine which volume is the boot and which is the data. A device ID is used to link an image or EC2 to the volumes.
