
## Personal Summary

  - supports multiple records with the same name. Each record can have it's own designated health check. 
  - Failed records will not be sent back to the client. 
  - Only healthy records will be sent back for the customer to select. 
  - Multi Value improves availability. It is NOT a replacement for load balancing. 
  - UP TO 8 "HEALTHY" RECORDS ARE RETURNED. IF MORE EXIST, 8 ARE RANDOMLY SELECTED.
