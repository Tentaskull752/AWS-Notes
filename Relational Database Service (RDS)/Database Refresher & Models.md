

## Personal Summary

 - Relational (Structured Query Language)
 - Structure in & between tables of data - Rigid Schema. Rigid means that it's defined in advance before adding anything to it
 - Fixed relationship between tables, defined in advance.

  - NoSQL - Not one single thing... different models
  - Generally a much more relaxed schema, weak or no schemas.
  - Relationships are handled differently as well.


  - In Relational, all data that relates to each other is stored in a single table. For ex. a table for data on the humans and another table on their pet animals. 
  - The key for each human or animal are linked, the human with the primary key of 1, owns the pet animal with the primary key ID of 1. The composite key lines up these Primary Key IDs, known as the Composite Key. 
  - And in the composite key, one ID can be linked to an ID in another table more than once.
