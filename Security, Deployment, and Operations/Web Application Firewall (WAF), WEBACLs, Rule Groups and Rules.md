
- Web Access Control (WEBACL)
- Rules within Rule Groups
- Rule Groups within WEBACL
- Can update WEBACL's manually or using EventBridge or Scheduled Rules to implement blocked IP lists to prevent bad actors. 
- Data from S3, CW Logs, Firehose, can be sent through Lambda and then to WEB ACL to auto-adjust rule groups.
- Architecture is based on creating a feedback loop between logs generated by WAF / Applications or ecosystem data to update WEBACL
