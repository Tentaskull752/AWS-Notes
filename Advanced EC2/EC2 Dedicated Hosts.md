
## Personal Summary

 - This is a host that holds operating EC2 Instances.
 - You only pay for the host and it's capacity size, you do not pay for the ec2 usage on the host. 
 - It is dedicated to a pre-specified family of ec2 instance types.
 - On-Demand & Reserved Options available.
 - Host Hardware has physical sockets and cores.
 - For ex. an A1 host has 1 socket/16 cores; can hold 16 medium, 8 large, 4 x-large, 2xx-large, or 1 xxx-large.
 - The configuration of the instance types is customizable. Does not have to be one type of instance. 
 - AMI Limits - RHEL, SUSE Linux, and Windows AMIs aren't supported
 - Amazon RDS instances are not supported
 -  Placement groups are not supported for Dedicated Hosts
 - Hosts can be shared with other ORG Accounts....RAM
