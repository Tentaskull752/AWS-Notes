
## Personal Summary

  - Enhanced Networking:
	  - Uses SR-IOV - NIC is virtualization aware. Host has Interface that are aware that virtualization aware. 
	  - Higher I/O & lower host cpu usage. 
	  - More Bandwidth
	  - Higher Packets-per-second (pps)
	  - consistent lower latency due to host not being in the middle of giving access each virtual instance to the interface chip.

 - EBS Optimized:
	 - EBS = block storage over the network
	 - Historically network was shared, data and EBS
	 - EBS Optimized means dedicated capacity for EBS
	 - Supported by my instances and is on by default
	 - Some support, but enabling costs extra
